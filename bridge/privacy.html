AI Studio Bridge TEST2 ホーム

プライバシーポリシー

対象アプリ: AI Studio Bridge TEST2
運用者: GitHub アカウント tomomu1-cmd（本人運用）
更新日: 2026年10月27日

1. 利用者と目的

本アプリは運用者本人だけが使う個人用の同期ツールです。本人が選択した TEST2 用 Google ドキュメントの作業指示を読み、既存の作業記録と照合し、進捗文書へ受領・進捗・保留などを追記するためにデータを扱います。

2. アクセスするデータと OAuth

本人が Google の正式な同意・ファイル選択を通して許可した既存 2 文書の本文、文書 ID、タブ ID、改訂情報を扱います。要求する Google API 権限は https://www.googleapis.com/auth/drive.file のみです。現在の実装では対象 2 文書を固定し、指示文書は読取りのみ、進捗文書は末尾への追記と保存結果の読戻しに制限します。文書の削除や履歴整理は行いません。

定期処理を本人の再操作なしで続けるため、オフラインアクセスを使用します。アクセス用・更新用トークンと専用 OAuth クライアント設定を、本人の Windows ユーザーに結び付く DPAPI で暗号化し、本人専用アクセス制限のある領域へ保存します。Google のパスワードは取得・保存しません。

3. 保存場所・ログ・保管期間

作業指示と進捗本文は本人管理の Google ドキュメントに保存します。文書本文は処理中にメモリ上で扱い、Bridge の同期状態には処理済みメッセージ ID、照合用ハッシュ、関連する作業 ID、時刻などを保存します。実行結果・エラー分類・照合記録は本人管理の Windows および既存の Google Drive 作業記録に保持します。認証情報の値をログや公開ページへ記録しません。

自動で一定期間後に削除する仕組みは現在設けていません。作業記録は本人が運用・確認・復旧に必要とする期間保持し、整理・削除は本人の判断で行います。認証情報は利用継続中に保持し、不要になった場合は本人が認可を取り消し、専用保管データを削除できます。

4. 外部サービスとデータ提供

Google の認証・トークン更新と Google Docs API を利用し、選択された文書の読取り・追記を行います。認可の失効などで接続を停止する場合は、既存の ntfy 通知経路へ接続停止と再認可の必要性だけを通知します。この通知に文書本文やトークンの値は含めません。

本アプリは Google ユーザーデータを販売せず、広告や一般向けの分析に利用しません。Bridge の同期処理から文書本文を外部 AI API へ送信する機能はありません。本人が別途利用する AI チャットやコネクタを通じた閲覧・利用は、そのサービス側の設定と規約に従います。

この案内サイトは GitHub Pages で配信します。ページに独自のアクセス解析、広告、ログインフォームは設置していません。GitHub および Google など各サービス自体による情報の取扱いは、各社のプライバシーポリシーに従います。

5. Google データの利用制限

本アプリによる Google API から受け取った情報の利用および他のアプリへの転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。Google 文書の内容を汎用 AI・機械学習モデルの学習に使用する機能はありません。

6. 認可の取消・削除

Google アカウントの接続管理から本アプリへのアクセスを取り消せます。認可を取り消すと、その認可による同期は継続できなくなります。取消は Google ドキュメントや既存の作業記録の自動削除を意味しません。文書・処理記録・専用暗号化保管データの削除が必要な場合は、本人が既存運用の手順で行います。他アプリの認証情報には触れません。

7. 問い合わせ・変更

本アプリとデータの取扱いについての問い合わせ先: tomomu1@gmail.com。取扱いを変更する場合は、このページの内容と更新日を更新します。
